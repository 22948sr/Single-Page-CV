# Single-Page CV – Sanju Rathee

A structured, single-page CV (Curriculum Vitae) built using only HTML. The focus of this project is on semantic markup, SEO best practices, and Open Graph tags. Styling will be addressed in a future project.

---

## Features

- Semantic HTML5 structure using tags like `<header>`, `<main>`, `<section>`, `<article>`, and `<address>`
- SEO meta tags: description, keywords, author, and robots
- Open Graph (OG) tags for rich social media sharing previews
- Favicon linked in the head section
- Fully accessible with `aria-labelledby` attributes on all sections
- Clean, readable layout with sections for Summary, Skills, Education, Experience, Projects, and Certifications

---

## Sections Included

1. **Professional Summary** – Overview of experience and expertise
2. **Skills** – Categorized into Web Development, Digital Marketing, Infrastructure, AI Tools, and Professional Tools
3. **Education** – MCA and BCA degrees with institutions and dates
4. **Experience** – Three roles with bullet-point achievements and skills used
5. **Key Projects & Websites** – Eight live websites developed and managed
6. **Certifications** – FreeCodeCamp and SachTech certifications
7. **Across the Internet** – Links to live websites

## How to Use

1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. No dependencies, frameworks, or a server are required
